# 楽天MT4 用 自動売買EA（PricePercentEA）

`PricePercentEA.mq4` は、価格と％で売買する戦略（ナンピン・トレーリング対応）を
**MetaTrader 4 のEA（自動売買プログラム）**として実装したものです。楽天証券の
**楽天MT4** をはじめ、一般的なMT4で動作します。

> ⚠️ FX自動売買は損失リスクがあります。**必ずデモ口座で十分に検証**してから、自己責任で。
> 特にナンピンは含み損を抱えたまま積み増すため、相場が一方向に動くと損失が急拡大します。

---

## 1. インストール手順（楽天MT4）

1. 楽天MT4 を起動してログイン（**まずはデモ口座を推奨**）。
2. メニュー **［ファイル］→［データフォルダを開く］** をクリック。
3. 開いたフォルダの **`MQL4\Experts`** に `PricePercentEA.mq4` をコピー。
4. MT4に戻り、**ナビゲーター**ウィンドウの「エキスパートアドバイザ」を右クリック →
   **［更新］**（または MT4 を再起動）。`PricePercentEA` が一覧に出ます。
   - 自分でコンパイルする場合は、`MQL4\Experts` の .mq4 を **MetaEditor** で開いて
     **［コンパイル］**（F7）。エラー0で `PricePercentEA.ex4` が生成されます。

## 2. 自動売買を許可する

1. MT4 ツールバーの **［自動売買］** ボタンをON（緑の状態）にする。
2. **［ツール］→［オプション］→［エキスパートアドバイザ］** タブで
   **「自動売買を許可する」** にチェック。

## 3. EAをチャートに適用

1. 取引したい通貨ペア（例: **USDJPY**）のチャートを開く。
2. ナビゲーターから `PricePercentEA` を**チャートにドラッグ＆ドロップ**。
3. 設定画面の **［全般］** タブで「自動売買を許可する」にチェック。
4. **［パラメーターの入力］** タブで下表のパラメータを設定 →［OK］。
5. チャート右上に **顔マーク（😊）** が出れば稼働中。チャート左上に現在の状態
   （建玉数・平均建値・損益％など）が表示されます。

## 4. パラメータ一覧

| パラメータ | 意味 | 既定 |
|---|---|---|
| `Direction` | 0=買い(押し目) / 1=売り(戻り) | 0 |
| `EntryDropPct` | anchorから何%動いたらエントリ | 0.5 |
| `TakeProfitPct` | 利確%（平均建値ベース、0で無効） | 1.0 |
| `StopLossPct` | 損切り%（0で無効） | 2.0 |
| `TrailAnchor` | ノーポジ時にanchorを有利方向へ追従 | true |
| `NanpinEnabled` | ナンピン（増し玉）を使う | false |
| `NanpinStepPct` | 初回建値から何%ごとに増し玉 | 0.5 |
| `MaxNanpin` | 最大増し玉回数 | 3 |
| `NanpinSizeMult` | 増し玉ごとのロット倍率 | 1.0 |
| `TrailingEnabled` | トレーリングストップを使う | true |
| `TrailingPct` | 最有利値から何%戻したら手仕舞い | 0.5 |
| `TrailingActivatePct` | 含み益が何%でトレーリング開始(0=常時) | 0.5 |
| `RiskPerTradePct` | 1トレードのリスク(口座残高%) | 1.0 |
| `FixedLots` | >0なら固定ロット（リスク計算より優先） | 0.0 |
| `MaxLots` | 最大ロット上限 | 5.0 |
| `Slippage` | 許容スリッページ(point) | 10 |
| `MagicNumber` | EA識別番号（他EAと重複しない値） | 20240601 |

判定の優先順位は **損切り → トレーリング → 利確 → ナンピン**。
`StopLossPct` を `NanpinStepPct` より小さくすると増し玉前に損切りされるため、
ナンピンを効かせたい場合は損切りを広め（または0=無効）に設定します。

## 5. バックテスト（ストラテジーテスター）

MT4 には標準のバックテスト機能があります。

1. **［表示］→［ストラテジーテスター］**（Ctrl+R）を開く。
2. 「エキスパートアドバイザ」に `PricePercentEA`、通貨ペア・期間・スプレッドを設定。
3. **［スタート］** で過去データに対する成績（損益曲線・最大DD等）を確認。
4. 「最適化」を使うと `EntryDropPct` などのパラメータを総当りで探索できます。

> ヒストリカルデータの精度（ティック/分足）で結果は変わります。実運用前にデモでも確認を。

## 6. 停止のしかた

- 一時停止: ツールバーの **［自動売買］** ボタンをOFF。
- EAを外す: チャートを右クリック →［エキスパートアドバイザ］→［削除］。
- ※EAを外しても**既存の建玉は残ります**。必要なら手動で決済してください。

## Python版との関係

- **戦略ロジックは Python版 `PricePercentStrategy` と同一**です。
  Python側（このリポジトリのルート）では、ブラウザUIや `backtest` コマンドで
  手早くパラメータの感触を掴めます。
- 感触を掴んだら、同じ数値をこのEAに設定して **楽天MT4のデモ口座**で検証 → 実運用、
  という流れがおすすめです。
